## Currently

🚀 **Lead Software Engineer at [VBSV](https://ouigoal.vbsv.fr)**, working on **OuiGoal**, an affordable goal-line technology system for football stadiums.

- Real-time ball detection from four high-speed cameras, with decisions delivered in under 200 ms
- On-device AI inference on an edge computer, with no cloud dependency
- A remote management platform for deploying and supervising the system
- OuiGoal is part of the **FIFA Innovation Programme 2025–2027**
